Help & User Guide

Step-by-step instructions for front-desk and administrative staff.

Back to dashboard

1. Logging in

Starting a clinic session

  1. Open the systemThe sign-in screen appears automatically.
  2. Enter your credentialsUse the username and password issued by the clinic administrator.
  3. Select "Sign in"The clinic server verifies your account and opens the dashboard.
  4. If sign-in failsRead the red message above the form and check that the username and password have been entered correctly. Contact the system administrator if the problem continues.

2. Registering an appointment

Booking a patient visit

  1. Open Appointments → Register appointmentOr use the "New appointment" button on the dashboard.
  2. Complete the patient detailsName, address and a 10-digit contact number.
  3. Choose dentist, treatment, date and timeClinic hours are 08:00 – 19:30.
  4. Select "Submit appointment"The server checks dentist availability and issues the appointment number.
  5. Give the number to the patientIt is displayed in the green confirmation panel and is needed for all future actions.

3. Searching for an appointment

Finding an existing booking

  1. Open Appointments → Search appointment
  2. Type the appointment numberFor example APT-2026-0143.
  3. Select "Search"The full record and its current status are displayed.
  4. Nothing found?A friendly message is shown — re-check the number on the patient slip.

4. Updating or cancelling

Amending a booking

  1. Open Appointments → Update / CancelEnter the appointment number and select "Load record".
  2. Edit the detailsAny field can be corrected, including the dentist and time slot.
  3. Select "Update appointment"Confirm the dialogue; availability is re-checked by the server.
  4. To cancelSelect "Cancel appointment" and confirm. The slot is released and the status becomes cancelled.

5. Generating a bill

Charging for a completed visit

  1. Open BillingEnter the appointment number and select "Find appointment".
  2. Check the patient and treatment summaryMake sure the correct visit has been loaded.
  3. Select "Generate bill"The server calculates the consultation fee, treatment fee and total.
  4. Select "Print receipt"A clean, print-friendly receipt is produced for the patient.

6. Viewing reports

Daily and financial summaries

  1. Open ReportsThe last seven days are loaded by default.
  2. Choose a periodSet the from/to dates and select "Apply period".
  3. Review the tablesAppointments by date, appointments by dentist, treatment frequency and revenue.
  4. Print if requiredUse "Print report" to produce a copy for the clinic manager.

Logging out

Ending your shift safely

Select Logout in the sidebar or in the top-right corner and confirm. The clinic server ends your session and you are returned to the sign-in screen. Always log out before leaving the reception desk unattended.

Frequently asked questions

Why was my appointment rejected?

The server refuses bookings that clash with an existing appointment for the same dentist, or that fall outside clinic hours. The reason is displayed in the red message above the form.

Can I change a fee on the billing page?

No. Fees come from the treatment price list held in the clinic database and are calculated by the server, which prevents billing errors. Contact the administrator to amend a price.

A cancelled appointment still appears in search.

Records are never deleted — cancelling only changes the status to "cancelled" so the clinic keeps a complete history for reporting.
